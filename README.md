# Firewell CCG — первый срез ядра

Источник правил: предоставленные документы v0.9.12. Это начало разработки, а не готовая PvP-игра.

## Запуск

Нужен Node.js 24+; `npm test` запускает тесты встроенным `node:test`. Зависимости и сборщик пока не нужны. Для локального тестового сервера задайте длинный пароль в переменной `FIREWELL_ALPHA_PASSWORD` (не менее 12 символов), затем `npm start`. Откройте `http://localhost:3000` в двух раздельных браузерных сессиях, введите пароль, создайте комнату и передайте её код второму игроку. Слушающий адрес для публичной сети настраивается через HTTPS-прокси; не выставляйте этот HTTP-процесс напрямую в интернет.

## Что работает

- Версионированное сериализуемое состояние, команды с ревизией и ключом идемпотентности.
- Ручные тестовые сцены с двумя Владетелями по 30 HP; проверка состава 70-карточной колоды.
- Первый ход без обычного добора, последующие ходы с добором, пустая колода без усталости.
- Одно Владение за ход, истощение и обновление Владений, раздельная цветная/нейтральная Энергия, оплата Существа в основную зону 8 мест.
- Очистка Энергии и выбор сброса до 8 карт в конце хода.
- Базовая адресная атака с отдельным выбором перехватчика защитником, Страж, Полёт при перехвате, Щит.
- Чистый планировщик Жертвы: обе зоны, совпадение цветов, запреты статусов, N разных участников и воспроизводимое предложение трёх наград из пяти. Планировщик пока не разрешает гибель и награду.
- Запускаемый тестовый сервер 1×1: пароль альфы, две сессии, комнаты по коду, серверная проверка команд, сохранение матча в SQLite, скрытая рука противника и мобильная доска для базовых действий.

## Намеренно закрытые действия

Текущий матч использует временную демонстрационную колоду с гарантированным Владением в первых семи картах; полноценная раздача/муллиган ещё не реализованы. Пока отсутствуют продвинутый бой (Первый удар, Пробивание, Похищение жизни, Легенды), действующие способности, размещение в 4 вспомогательных местах, полное разрешение Жертвы и награды, таймеры, полноценные аккаунты, редактор и обучение. Карты с неподдерживаемой способностью допустимы без неё; интерфейс явно предупреждает об этом. Ритуальное Стирание при попадании в Сброс реализовано как общий маршрутизатор зон, но полный ритуал не запущен. Никакой результат планировщика не считается наградой до завершения обязательных предсмертных последствий.

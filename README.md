# Firewell CCG — первый срез ядра

Источник правил: предоставленные документы v0.9.12. Это начало разработки, а не готовая PvP-игра.

## Запуск

Нужен Node.js 22.10+; `npm test` запускает тесты встроенным `node:test`. Зависимости и сборщик пока не нужны.

## Что работает

- Версионированное сериализуемое состояние, команды с ревизией и ключом идемпотентности.
- Ручные тестовые сцены с двумя Владетелями по 30 HP; проверка состава 70-карточной колоды.
- Первый ход без обычного добора, последующие ходы с добором, пустая колода без усталости.
- Одно Владение за ход, истощение и обновление Владений, раздельная цветная/нейтральная Энергия, оплата Существа в основную зону 8 мест.
- Очистка Энергии и выбор сброса до 8 карт в конце хода.
- Базовая адресная атака с отдельным выбором перехватчика защитником, Страж, Полёт при перехвате, Щит.
- Чистый планировщик Жертвы: обе зоны, совпадение цветов, запреты статусов, N разных участников и воспроизводимое предложение трёх наград из пяти. Планировщик пока не разрешает гибель и награду.

## Намеренно закрытые действия

Пока отсутствуют стартовая раздача/муллиган, продвинутый бой (Первый удар, Пробивание, Похищение жизни, Легенды), действующие способности, размещение в 4 вспомогательных местах, полное разрешение Жертвы и награды, таймеры, серверная сеть, секретность рук и редактор. По решению автора карты с неподдерживаемой способностью допустимы без неё; будущий интерфейс обязан явно предупреждать об этом. Ритуальное Стирание при попадании в Сброс реализовано как общий маршрутизатор зон, но полный ритуал не запущен. Никакой результат планировщика не считается наградой до завершения обязательных предсмертных последствий.

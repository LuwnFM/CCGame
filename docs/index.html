Настройка поля

Выбери устройство, затем нажми на элемент в предпросмотре. Размеры сохраняются в этом браузере сразу.

Устройство

Размер экрана меняет только предпросмотр. Настройки устройства применятся в игре по ширине и ориентации окна.

Выбранный элемент

Нажми на элемент справа.

Настройки

Файл JSON можно прислать разработчику, чтобы закрепить размеры для всех игроков. Пока они действуют только в этом браузере.

Предпросмотр интерфейса

Выбери экран и окно, затем нажми на нужный текст, рамку или кнопку. В режиме просмотра кнопки макета можно нажимать.

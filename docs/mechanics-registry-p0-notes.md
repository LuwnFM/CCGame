# P0.1 — машинно-читаемый реестр механик

`docs/mechanics-registry.json` является инвентарём известных серверных механик версии 0.9.15-alpha. Он различает **наличие модуля** и **работающую реализацию** через `implemented`. Для `ward` указано `false`; тест запрещает этот kind в каталоге карт. Четыре исторических адаптера помечены `deprecatedAlias`.

Поля `ui: legacy/manual` означают, что синхронизация клиентского интерфейса с реестром **не готова**. Значения `targetRules`, `timing`, `en`, `introducedIn` пока описательные, а не машиноисполняемые правила; их детализация — следующие задачи P0. Не используйте этот инвентарь вместо утверждённых правил игры.

Проверка `test/mechanics-registry.test.ts` сравнивает реестр с фактической регистрацией обработчиков, файлами и эффектами карт, отклоняет неизвестные или неработающие эффекты. Она включается в существующий `npm test` через маску `test/*.test.ts`. Отдельный запуск тестов в этой сессии не выполнялся.

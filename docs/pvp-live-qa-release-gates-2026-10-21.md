## Другие механики, требующие нормативной спецификации

В дорожной карте и docs/decisions-v0.9.13.md отмечены как недоделанные: **Предвидение, Отклик Владения, настоящий Оберег, Детонация, Рикошет**, единая очередь эффектов и атомарная обработка всех событий. Не имитировать их работающими без утверждённых параметров. Не путать их со Щитом или существующими боевыми способностями.

Архив v0.9.12 включал требования по 324 сценариям. Действующие более поздние решения и код имеют приоритет при конфликте. Ни один сценарий нельзя объявлять пройденным только по заголовку или комментарию; нужен автоматический тест либо ручная воспроизводимая проверка.

## Инфраструктура и статус

Railway: project `Firewell CCG Staging`, service `firewell-ccg-alpha`, branch `codex/initial-rules-core`, mounted SQLite `/data/firewell.sqlite`; публичный URL `https://firewell-ccg-alpha-staging.up.railway.app`. Профили с выключенного Windows-ПК не переносить; пользователь согласовал регистрацию заново. Новый общий пароль альфы находится в Railway env, не в репозитории.

Основной URL должен быть только `https://ccgame-omega.vercel.app`. Vercel production alias до успешного переключения всё ещё на старом backend. **Не сообщать, что основной сайт готов, до GET /api/health через ccgame-omega.vercel.app с JSON `{ok:true,service:'firewell-ccg'}`**.

Railway Trial/Free имеет кредитные лимиты. Учитывать расход, периодически делать внеплатформенный backup, не делать финансовых обещаний без панели Billing.

## Гейт выпуска обновлённого PR #2

1. Текущая ветка PR #2 проходит все Node тесты и Chromium E2E на **точном HEAD SHA**. После прогона e444… выяснилось: hang после mobile screenshot перед завершением cross-origin теста. Исправлена очистка keepalive при остановке фикстур, добавлен online/offline health UI тест. Нужна новая проверка.
2. Контракт данных и версия клиента соответствует активному backend; не показывать старый UI новым матчам.
3. Никаких обновлений игры с разрывом текущих комнат без безопасного A/B. Для первой миграции пустой Railway-БД допустима при отсутствии активных игроков и отдельной договорённости.
4. Подтвердить функциональность игры через Vercel API rewrite на Railway, а не просто страницу Railway.
5. Релиз П0-пунктов и баланс не объявлять закрытыми, пока нет объективных проверок.

## Выбор для Firewell

Чистый TypeScript движок получает команды и возвращает новое сериализуемое состояние/события. Данные карт декларативны и версионированы; клиент рисует состояние и отправляет намерения. Сервер один принимает правила, случайные исходы, таймеры и оплату. Персистентность и транспорт остаются снаружи ядра. Это позволяет сначала полно проверить очереди, ритуалы и перехваты, затем подключить онлайн-комнаты; при необходимости подходит [Colyseus](https://docs.colyseus.io/) для комнат и синхронизации. Первоначальный сервер может держать матчи и учётные записи в SQLite на одном экземпляре.

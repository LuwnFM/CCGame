# Firewell CCG — решения после интерактивного опроса

Дата: 2026-10-21. Основа: правила v0.9.12 и ответы автора в чате. При конфликте с прежними предложениями решения ниже имеют приоритет. Незаданные значения карт остаются в их тексте; этот документ не создаёт готовый каталог карт.

## Ритуал

- Каждая Техника может создавать длительный эффект `Ритуал (N)` со своим цветом, эффектом, пулом и сроком. Связь эффекта с присутствием карты-источника определяется текстом карты. Единого N для всех Техник нет: сравнить 3, 4, 5.
- Многоцветная Жертва подходит к ритуалу, если содержит требуемый цвет. Нейтральная Жертва относится к отдельному нейтральному ритуалу; она не универсальная для цветных.
- При начале собственного хода игрок выбирает один из готовых источников, потом ровно N подходящих Жертв. Допустимость (включая запреты Величественного, Ошеломления и Стазиса) и параметры фиксируются при начале. Дальнейший уход источника не отменяет начатое разрешение.
- За одно начало хода не более одного ритуала, даже если триггер создал новый пакет. Невыбранные эффекты сохраняются до собственного срока.
- Гибель группы и вся обязательная цепь последствий завершаются до выдачи награды.

## Награда и поле

- Из пула пяти соответствующего цвета сервер равновероятно предлагает три разных результата. Пул и версия карт закреплены на начало матча; временная невозможность размещения не исключает результат из предложения. Уникальность обрабатывается общим правилом при появлении. При тайм-ауте выбор одной из трёх случаен и записан в журнал.
- Нетокеновая награда идёт в основное поле. Если все восемь мест заняты, контроллер может выбрать одно **не Величественное** своё основное Существо для ритуального замещения. Это обычная гибель со всеми событиями и последствиями, даже если поле было полным до ритуала.
- Токен-награда идёт только во вспомогательное поле; при полноте применяются обычные правила Вытеснения. Нельзя превышать 8+4.
- Если выбранную награду нельзя разместить, сервер повторно равновероятно выбирает одну из всех пяти наград и выдаёт её в руку. Результат может быть токеном как временной картой в руке. Предел восьми карт проверяется в конце собственного хода.
- Ритуальное Существо-награда несёт метку происхождения через зоны и смену контроллера. **Любая попытка отправить ритуальную награду в Сброс заменяется Стиранием**, в том числе после гибели, сброса из руки или Вытеснения. При гибели сначала регистрируются обязательные события гибели/выхода, затем выполняется Стирание. Возврат в руку не стирает награду сам по себе. Токены, не существовавшие в колоде, также окончательно исчезают при попытке попасть в Сброс.

## Вытеснение, выбор, типы

- Величественный предмет может добровольно уйти иным способом только по явному тексту карты.
- Массовое создание частично разрешается, если законных мест хватает лишь для части. Контроллер выбирает подмножество до размещения, оплаченная стоимость сохраняется.
- Обязательность создания определяется текстом эффекта, а не техническим типом триггера. Если экран любого выбора уже открыт и игрок не ответил, сервер выбирает случайное законное действие. Отказ не участвует в случайном выборе, пока есть положительное законное действие. При отсутствии законных действий эффект не выполняется. Это новое уточнение заменяет прежнее правило №35 о пропуске создания при тайм-ауте.
- Предмет нельзя разыграть при полном вспомогательном поле без законного места или Вытеснения. Смена основного механического типа, требующая переноса между секторами, по умолчанию запрещена; исключения требуют явного текста и отдельной проверки.

## Безопасность и статусы

- Сервер последовательно принимает команды с ожидаемой ревизией и ключом идемпотентности; проигравшая гонку команда получает актуальное состояние. Числовой бюджет операций подбирается стресс-тестами.
- Если обязательная цепь не заканчивается в бюджете, вся исходная команда откатывается до подтверждённого состояния, матч приостанавливается без победителя. Возобновление после исправления причины с тем же журналом и seed.
- Под Стазисом способность «при гибели» подавляется по состоянию в момент гибели. Повторный Стазис заменяет оставшийся срок новым N. Ошеломление может сосуществовать; Отрава после паузы тикает в ближайшее собственное начало хода контроллера поражённого Существа.
- `Сковывание`: если Ошеломления нет, накладывает Ошеломление вместо Стазиса; если есть, преобразует его в Стазис(N). Повторное наложение применяет замену срока. Обычный Стазис сам по себе не запускает эту конверсию.
- `Детонация` и `Рикошет` работают лишь по явному тексту карты. Небоевой предмет без здоровья не получает обычный урон. Подавленная Немотой аура восстанавливается сразу при снятии Немоты.

## Первый набор и продукт

- Копирование и смена контроля отложены до следующего этапа. Предвидение, Отклик Владения и Оберег(N) нужны в первой версии.
- Карту с ещё не реализованной способностью можно играть без неё; интерфейс обязан прямо показать, что способность временно не действует. Это разрешение автора не означает, что такую карту следует использовать для проверки баланса.
- Пять фиолетовых наград имеют разные роли, но близкую общую ценность. Подготовить шесть тестовых 70-карточных архетипов.
- Первый результат — закрытая PvP-альфа по ссылке и специальному паролю. Доступ и все команды проверяются сервером. Для одного сервера сначала SQLite с миграциями и резервной копией; перейти на PostgreSQL при масштабировании.

## Предстоящие проверки

Тесты должны покрыть гибель при ритуальном замещении (включая новые триггеры), переброс в руку из всех пяти, токен-карту в руке, замену Сброса ритуальной награды при гибели/Вытеснении/сбросе из руки, тайм-аут с отказом, откат всей команды после цикла и гонку двух команд. Баланс N=3/4/5 остаётся измеряемым, а не заранее выбранным.

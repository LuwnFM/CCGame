# Firewell CCG · редактор стола

Самостоятельный статический предпросмотр без игрового API. Экран / и /layout-editor.html открывают редактор. Устройства, экраны игры, окна и свойства элементов доступны в панели. Изменения сохраняются в браузере этого адреса; JSON переносится в игровой клиент через импорт.

Vercel: Output Directory `redactorstola`; Git-автодеплой отключён в `vercel.json`. Проект разворачивается вручную из этой директории. При обновлении исходных `web/` файлы редактора и предпросмотра нужно заново скопировать сюда.

GitHub Pages (временно): источник GitHub Actions. Workflow `.github/workflows/editor-pages.yml` запускается только для `editor/redactorstola` и публикует `/docs` по адресу `https://luwnfm.github.io/CCGame/`. В окружении `github-pages` нужно разрешить деплой из этой ветки. Каталог `docs/` содержит независимую копию статических файлов. JSON скачивается и загружается локально в браузере; параметры устройства не отправляются на сервер.

Редактор поддерживает выбор экранов и окон, перетаскивание мышью или касанием, отдельные координаты для компьютера и двух ориентаций телефона, шрифты, цвета, размеры и каждую сторону рамки. Экспорт скачивает `firewell-layout.json`, импорт принимает этот файл на другом устройстве.

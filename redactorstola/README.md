# Firewell CCG · редактор стола

Самостоятельный статический предпросмотр без игрового API. Экран / и /layout-editor.html открывают редактор. Устройства, экраны игры, окна и свойства элементов доступны в панели. Изменения сохраняются в браузере этого адреса; JSON переносится в игровой клиент через импорт.

Vercel: Output Directory `redactorstola`; Git-автодеплой отключён в `vercel.json`. Проект разворачивается вручную из этой директории. При обновлении исходных `web/` файлы редактора и предпросмотра нужно заново скопировать сюда.

GitHub Pages (временно): источник `editor/redactorstola` → `/docs`; публикация `https://luwnfm.github.io/CCGame/` после включения Pages. Каталог `docs/` содержит независимую копию статических файлов. JSON скачивается и загружается локально в браузере; параметры устройства не отправляются на сервер.

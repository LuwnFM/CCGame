# Каталог Firewell CCG
В каждой цветовой папке `src/cards/<цвет>/<тип>/<имя>.ts` теперь лежит отдельная карточка с ID, стоимостью, характеристиками, лором и сериализуемыми параметрами эффектов. `index.ts` цвета перечисляет карты стартовой колоды и количество копий; `src/cards/catalog.ts` агрегирует всё, включая дополнительные Владения. `src/decks.ts` лишь клонирует определения и проверяет 70-карточные колоды.
Призыв — универсальный `summon(game,actor,cards)` в `src/mechanics/zones.ts`; новая карта передаёт объекты токенов как данные `{kind:'summon',cards:[...]}`. Специальных процедур для скелета или конкретной карты больше не требуется. Старые коды эффектов поддерживаются адаптерами для архивных матчей.
Для новой карты создайте отдельный файл, затем добавьте один import и запись с числом копий в цветовой `index.ts`. Публичные ID сохраняйте, иначе понадобится миграция сохранённых колод.
